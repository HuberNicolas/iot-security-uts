# iot-security

> Weekly labs, exercises, and assignments from the IoT Security course at the University of Technology Sydney, covering network security, vulnerability analysis, and IoT protocol security.

## ✨ TL;DR
Open the relevant week directory (`w1`–`w11`) and follow the instructions in `instructions/`.

## 🚀 Features
- **11 course weeks:** Hands-on exercises on IoT security topics for each course week.
- **Lab tasks:** Instructions (`instructions/`), solutions (`solutions/`), and source code (`src/`).
- **Practical topics:** Network protocol analysis, vulnerability scanning, and IoT device security.

## 🎓 Academic Context
This project was created as part of a university course.
- **Course:** IoT Security (48730)
- **Institution:** University of Technology Sydney (UTS)
- **Semester:** Spring Semester 2024 (exchange semester)

---

## 🛠️ Installation

### Prerequisites
Varies by week (e.g., Wireshark, Python, Metasploit). See the `instructions/` folder in each week's directory.

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/iot-security
cd iot-security
```

---

## 💻 Usage

Navigate to the relevant week directory and work through the tasks in `instructions/`.
